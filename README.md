# Old Penarthians RFC — Design System

The brand and design system for **Old Penarthians RFC** ("Old Pens" / OPRFC), built from the club's **2025 Brand Guidelines**.

## ⬇️ Download

**[Download the full kit (zip, 1.5 MB)](https://github.com/CavershamDigital/old-pens-rfc-design-system/raw/main/Old-Pens-RFC-Design-System.zip)**

One file, everything inside. Unzip it and open `readme.md` for the full write-up.

## What's in the kit

| Folder | What it holds |
| --- | --- |
| `source/` | The original 2025 Brand Guidelines PDF |
| `assets/` | Club crest (transparent PNG), match photography, brand fonts (Montserrat, Bebas Neue, Old English) |
| `guidelines/` | Specimen cards for the colour palette, type scale, spacing, crest usage and clear space |
| `templates/` | Ready-to-use club documents: letterhead, memo, meeting agenda, meeting minutes, finance report, email signature, certificate |
| `components/` | UI components (buttons, inputs, cards, tabs, dialogs) styled to the brand |
| `ui_kits/club-site/` | Example club website screens — home, fixtures, join |
| `tokens/` | The colours, type and spacing as reusable CSS variables |

## The essentials at a glance

**Colours** — Golds `#EC9522` (lead), `#EBAE20`, `#FDDA31`. Blues `#24599D` (club blue), `#203A71`, `#14274C` (deep navy). Crest reds `#FF0025`, `#E02027`, `#B7000E`. Neutrals `#F3F3F3`, `#515151`, `#090B0C`.
Golds are for accents and standout calls to action; blues carry surfaces and primary actions; reds are reserved for warnings and "live" markers. Text on gold is always navy.

**Type** — Montserrat Bold for headlines, usually uppercase. Montserrat Light for body copy. Old English is for the club name only. Bebas Neue is for shirt and score numbers only.

**Crest** — never smaller than 50px wide, always with 50px of clear space around it.

**Imagery** — real match photography, warm and natural. Never illustration.

## Notes

- The templates are starting points, not finished paperwork — copy them and edit.
- Invoices are deliberately not included; those come straight out of Xero.
- The UI kit screens are original compositions, not copies of the current club website.
